# efin-money-bot

Telegram-бот компании EFIN на python-telegram-bot 22.8: личный кабинет агента (заявки,
доход, тарифы), админ-панель, помощник Efin AI и ежедневная рассылка. Данные в SQLite.
Язык бота, комментариев и сообщений пользователям: русский.

## Команды

- Запуск локально: `python run.py` (нужен `.env`, образец в `.env.example`).
- Тесты: `python -m pytest` (зависимости: `pip install -r requirements-dev.txt`).
- Линтер: `ruff check .` (правила в `ruff.toml`, включены только настоящие ошибки).

## Деплой

Код лежит на GitHub (Goyardvpn/efin-money-bot), оттуда обновление вручную подтягивается в
Amvera и делается пересборка. Точка входа `run.py`, постоянные данные в `/data`.
Перед правкой файлов, которые уже работают на сервере, думайте о том, что боевые базы
перезаписывать нельзя.

## Правила проекта

- Бизнес-правила заявок, тарифов и выплат описаны в навыке `project-conventions`.
  Прочитайте его, прежде чем менять `parser.py`, `database.py` или логику доходов.
- Новый оплачиваемый статус заявки добавляйте командой `/add-payable-status`.
- Секреты (`BOT_TOKEN`, ключи TokenBoom и GitHub) только в переменных окружения.
  Файлы `.env` и базы `data/*.db` не править и не коммитить: хуки в `.claude/` это блокируют.
- Модули подключаются в `run.py` через `install()` и подменяют функции из `bot.py`.
  Порядок подключения менять нельзя.
- После любых правок парсера и расчёта выплат запускайте `python -m pytest`.

## Ограничение хуков

Хук защиты секретов срабатывает на инструменты Edit и Write. Правку через команду Bash
(например, `sed -i .env`) он не видит, поэтому не просите Claude менять секреты командами.
