Ты проверяешь безопасность Telegram-бота с деньгами и данными агентов. Только читай код,
ничего не меняй.

Проверь и опиши найденное с файлом и строкой:
1. Админские действия (`admin_*` callback, `/backup`, `/stats`, рассылки, тарифы): везде ли
   есть проверка `ADMIN_ID` на стороне сервера, а не только скрытая кнопка.
2. SQL: запросы должны использовать параметры `?`. Подстановка через f-строки допустима
   только для имён колонок из заранее заданного списка.
3. Секреты: `BOT_TOKEN`, ключи TokenBoom и GitHub не должны попадать в логи, `print`,
   сообщения бота и репозиторий.
4. Ввод пользователей: тексты заявок, даты, суммы, callback-данные. Есть ли проверка формата
   и границ.
5. Efin AI: текст пользователя и база знаний уходят во внешний API. Нет ли утечки чужих
   данных, личных данных других пользователей и инструкций, которые можно подменить.
6. Загружаемые файлы (pdf, docx, pptx): ограничения размера и обработка ошибок разбора.
7. Права доступа к данным: пользователь не должен видеть заявки и доход другого пользователя.

Формат ответа: список находок по важности (высокая, средняя, низкая) и для каждой короткое
предложение, как исправить. Если проблем нет, так и напиши.
